# 腾讯会议录制同步

自动拉取腾讯会议云录制列表，提取分享链接，支持关键词模糊搜索，一键推送到钉钉群。

## 功能

- **自动获取录制链接** — 登录后自动拉取腾讯会议云录制，提取分享链接（含视频和转写）
- **模糊搜索** — 输入关键词任意片段，自动匹配会议名（如 `DEMO联咏` 可匹配 `联咏 Anasage DEMO 会议`）
- **强力搜索** — 可选翻遍全部录制历史，找到最早的关键词匹配
- **钉钉推送** — 配置钉钉机器人 Webhook 后，一键推送链接到群
- **登录态持久化** — 首次扫码登录后，cookie 本地保存，后续无需重复登录
- **GUI 桌面应用** — tkinter + ttkbootstrap 简洁界面，双击即用

## 安装

### 1. 环境要求

- Python 3.10+
- Chromium 浏览器（脚本会自动安装）

### 2. 下载

```bash
git clone https://github.com/ylei4882-ctrl/meeting-sync.git
cd meeting-sync
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
python -m playwright install chromium
```

## 使用

### GUI 模式（推荐）

```bash
python meeting_app.py
```

或双击桌面的 `Meeting-Sync.vbs` 快捷方式。

### 命令行模式

```bash
# 获取最近录制
python meeting_sync.py

# 按关键词搜索
python meeting_sync.py 联咏
```

### 钉钉机器人配置

1. 打开钉钉群 → 群设置 → 智能群助手 → 添加机器人 → 自定义机器人
2. 安全设置选「自定义关键词」，填入 `录制`
3. 复制 Webhook 地址，粘贴到应用中
